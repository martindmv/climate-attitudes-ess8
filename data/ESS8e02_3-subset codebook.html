dweight

Design weight
Location in questionnaire: R17
Note: For advanced users who may want to model a nonresponse correction themselves we provide a design weight (dweight). This weight corrects only for differential selection probabilities. Please note that we do not recommend use of this weight without non-response correction. For more information, please see the document "Weighting ESS data (User guide).

pspwght

Post-stratification weight including design weight
Location in questionnaire: R18
Note: We also provide the post-stratified design weight (without the population size correction), pspwght. This weight can be used for single country analysis or for cross-country comparisons and for these types of analyses should give you the same estimates as anweight. For more information, please see the document "Weighting ESS data (User guide).

pweight

Population size weight (must be combined with dweight or pspwght)
Location in questionnaire: R19

anweight

Analysis weight
Note: It is recommended that by default you should always use anweight (analysis weight) as a weight in all analysis. This weight is suitable for all types of analysis, including when you are studying just one country, when you compare across countries, or when you are studying groups of countries. For more information, please see the document "Weighting ESS data (User guide).
